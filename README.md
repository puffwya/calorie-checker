# Calorie Tracking Application

Full-stack calorie tracking platform built with Django and integrated with the USDA FoodData API.

## Overview

Developed a web application that allows users to search and track nutritional information for foods using external API data sources. Implemented backend systems for handling API requests, user data persistence, and activity tracking.

## Features

- USDA FoodData API integration for nutrition lookup
- User authentication system
- Calorie and macro tracking
- Persistent user data storage
- Backend logging and request handling

## Tech Stack

`Python` `Django` `REST APIs` `PostgreSQL` `USDA FoodData API` `Render`
